### 分层策略

| 层 | 规模 | 处置 |
|---|---:|---|
| L1 格式差异 | 1 | 规范化后直接取一致值，自动 |
| L2 多选 vs 单选形态 | 48 | 若一方答案集是另一方的**超集** → 取超集；否则转 L4 |
| L3 有解析且解析指向唯一答案 | 待统计 | 取「解析一致的答案」，自动 + 标记 |
| L4 剩余真实分歧 | ~200 | 按学科批量送**教材知识裁决**，每题输出 confidence；**低置信度不硬改**，改为标记 |

### 关键设计决定
- **不删除任何分歧版本**，只在题目上加：`answerAmbiguity: true` + `answerCandidates: [...]` + `answerResolved`。
- 网站侧：遇到歧义题显示"⚠️ 源数据答案存在分歧（已按 X 采纳）"，用户可自行切换查看。
- 系统解剖学 71 组是最大头，且正好在大一 → 可以优先过一遍（教材好查、图多）。
- 极光/python 的 75 个"见图"是**弱键误合并残留**（图片题无文本可比），需单独用「题干+图片标识」入键重跑去重，不属此 289。

**产出**：`answer_patch` 追加 + `conflicts_single_source_resolved.json`（含裁决/置信度/依据）。

## 4. 极光题干/选项损坏排查（P1）—— 重点结论：真损坏极少

### 实测结果（全库 43,791 唯一题，5 轮不同口径扫描）

| 检查项 | 命中 | 结论 |
|---|---:|---|
| 答案字母越界（答案 A 但选项无 A） | **0** | ✅ 全库干净 |
| 题干残留选项标记（`X.` 带点形态） | **1** | 传染病(test) 1 条，`A. 普通登革热` 残留在题干 |
| 题干残留选项标记（`X汉字` 无点形态） | **0** | ✅ |
| 选项值里塞了多个选项 | **15** | 其中 **14 条是误报**（如"维生素A、C、D、E"、"HLA-A、HLA-B" 本身是正常选项文本）；**1 条真损坏** |
| 选项键含 F+（超 5 选项） | **37** | 36 条合法（配伍题共享 6–8 备选、多选到底）；**1 条真损坏**：`H` 键里塞了 `印度 I尼泊尔 J不丹 K缅甸 L老挝 M越南` |
| 选项数 1–3 | **85** | 微生物 66 条是**填空题**（`blank_1..5` 格式，合法）；其余原题本就 2–3 选项 |
| 同题内选项文本全重复 | **141** | python 图片题 `{A:见图,B:见图,C:见图,D:见图}` → **图丢了**，不是选项丢了 |
| 题干/选项含 HTML 标签 | 69 / 10 | 需清洗 |
| 异常选项键名 | 124（`blank_1..5`） | ✅ 填空题正常格式 |

### 历史修复记录
`fix_option_mangling.mjs` 曾修复「备选选项被并入题干」的题：**免疫 7 + 生理 5 = 12 题**，只跑了 3 科，且检测只覆盖「带点」一种形态。

### 待修清单（总计 ~10 条 + 79 条清洗）

| 类别 | 量 | 处置 |
|---|---:|---|
| 题干残留选项 | 1 | 提回 `options`，清题干 |
| 选项值串行（H 里塞 I–M） | 1 | 拆分重排 |
| 选项值超长含选项文本 | 1 | 拆分 |
| HTML 标签 | 79 | 剥标签（保留 `<br>` 换行语义） |

| F+ 选项白名单 | 36 | 标记为合法配伍题 |

### 扩大检测口径（v2 脚本）
历史脚本只覆盖 3 科 × 1 形态。v2 要覆盖：
1. 全 61 科 × 三种形态（带点 / 无点贴附 / 尾随整段）
2. **主判据改用「答案越界」**（最可靠，当前 0）
3. 选项键连续性（有 A、C、D 无 B → 缺 B）
4. 选项数与题型基线比对（X 型应 ≥4；A1 应 4–5）
5. **选项语义校验**（新）：答案选项文本是否与题干语义匹配

### 需你配合的一件事（最有效）
你实际撞见"选项少了"的题，**给我一道具体题号或截图**，我直接定位真实形态。目前全库文本层扫描只找到 2 条真损坏——说明你看到的可能是：
- **渲染层**问题（网站把题干里的 `()` 或长文本截断，看起来像少选项）
- **iyixue 侧**数据（它的 options 是数组，合并时可能错位）
- 或就是那 2 条

凭一个实例比再扫 5 轮更省时间。
