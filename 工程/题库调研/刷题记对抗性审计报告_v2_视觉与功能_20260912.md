## 4. 对抗性重点：137 项测试为什么全绿却漏了这些

这是本次审计最有价值的部分——不是"测试不好"，而是**测试只覆盖它被要求覆盖的东西**：

| 盲区 | 根因 |
|---|---|
| 登录门禁 100% 未被测试 | `verify_jsdom.mjs:57` 只 eval `app.js / english.js / features.js`，**从不加载 `sync.js`**。真实页面里 `index.html:54` 是加载它的 |
| 云依赖不可见 | 测试用磁盘 fetch shim（`verify_jsdom.mjs:37-49`），跨域请求直接返回 404 假响应，永远看不到"站点依赖一个云函数才能打开" |
| 所有"视觉"断言都是字符串匹配 | 断言的是"CSS 里有 `tabular-nums`"、"`78ch`"、"`min-height:44px`"这些**规则存在性**。jsdom 没有布局引擎 → 网格空位、内容左对齐、canvas 模糊、暗色硬编码白块、hover 缺失，全部天然不可测 |
| "SW 缓存名带版本"是假通过 | 断言只检查常量里含 `shuati-` 前缀，语义（改版即失效）从未被验证；`CACHE` 实际是写死的 |
| 冒烟只点 41 次、每类 action 1 个 | 考试流程里"下一题缺失"是**按钮不存在**，而冒烟只验证"存在的按钮点了不报错"——缺失的按钮不会报错 |
| 数据断言不涉及体积 | `verify_site` 校验题数/字段/UUID，不校验 explain 分片 6.5MB 是否与 packs 一起被拉下来 |

## 5. 建议修复顺序

1. **P0-1 门禁**：要么加"离线使用（不同步）"出口并让文案与行为一致，要么直接把 `sync.js` 的门禁降级为可选账号卡。最小改动：`init()` 无 token 时不再 `showGate()`，改为注入一张可关掉的账号卡。
2. **P0-2 考试翻页**：`app.js:1212-1214` 考试未交卷时补 `下一题`（最后一题改为禁用/提示交卷），与 `nextQ()` 的边界逻辑对齐。
3. **P0-3 部署白名单**：建立只含 `index.html / *.js / *.css / data/ / sw.js` 的发布目录，把 `tavern/`、`.bak_*`、`_preview/`、zip、`database_export*.json` 挪出 `site/`。
4. **P1-8/9 桌面视觉**：合并两个 `@media(min-width:900px)` 块，`.mode-grid` 桌面改 `repeat(5,1fr)`、移动改 `repeat(2,1fr)` + 第 5 个跨列；`.view` 加 `margin-inline:auto`。
5. **P1-10/19 暗色与门禁**：把 `.qnav .qn` / `.qnav-legend .dot` / 热力图色阶 / `.auth-gate` 全部换成 token 或补 `body.dark` 档。
6. **P1-1~4 口径统一**：乱序刷题改用 `allQuestionsBoth`；练习会话键按来源分流（如 `r:` / `f:`）；题库章节下拉补分组维度；详情弹窗走 `Feat.optView()`。
7. **P2-1/2 性能**：explain 改为真正惰性（做题时按 id 取，或按章节切片）；SW 只缓存 shell + packs，给 Cache Storage 加体积上限。
