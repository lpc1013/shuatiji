# iyixue.top 前端借鉴清单（2026-09-12 归档）

> 调研素材：`工程/题库调研/前端调研/iyixue/`（25 张截图 + 全部页面元素快照）。
> 本清单为最终落地结论：**P0 已全部实现**，P1/P2 备查。

## 一句话结论
iyixue 的核心竞争力 = 好的筛选组题 + 掌握度状态机 + 完整的设置面板；其复习算法（自研 streak 启发式）和数据能力（无导出、无离线）不值得抄。

## 已落地（本次全量拉入）

| 优先级 | 功能 | iyixue 做法 | 我方落地 |
|---|---|---|---|
| P0 | 高级筛选组题 | 难度/年份/来源/题型/作答状态多维筛选后组卷 | `🔎 筛选组卷`（题库页入口），Feat.filterSetup/filterGo |
| P0 | 四级掌握状态 | 未接触→见过→熟悉→掌握，题目页可手动标 | Feat.MASTERY 四级 + masteryTag，错题/收藏列表可按状态筛 |
| P0 | 答案纠错反馈 | 4 类反馈（答案/解析/题干/其他），错题本汇总 | 题目页「纠错」chip + 设置页汇总/导出（Feat.openFeedback） |
| P0 | 偏好设置面板 | 自动下一题/滑动翻题/简洁模式等开关 | 偏好设置卡（含开关组 + 备考日期 + 每日目标合并） |
| P0 | 题目元信息条 | 年份/来源/难度/热度/正确率 标签行 | playerMetaHtml（showMeta 开关控制） |
| P0 | 笔记 | 题目绑笔记 | 题目页「笔记」+ 设置页列表/导出 |

## 不建议照搬
- **复习算法**：iyixue 用自研 streak 启发式；我方用 SM-2 风格间隔复习（stage/nextReview），更严谨。
- **无用户数据导出**：我方已有 JSON 导出/导入 + 云同步。
- **登录体系**：iyixue 登录同步未实装，我方纯本地 + 可选云同步更实用。
- **无离线包**：我方分片懒加载 + localStorage 已够用。
