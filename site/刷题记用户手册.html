一、快速入门

打开就能用

无需安装、无需注册、无需联网（首次加载后）。所有数据保存在你的浏览器里，换个设备或清空浏览器缓存会丢失进度——建议在固定设备上使用。

学一门题的完整流程

1
顺序刷题 → 选一章开始，逐题过一遍，把不会的揪出来
2
乱序刷题 · 仅错题 → 把做错的集中消灭
3
间隔回顾 → 系统按遗忘曲线自动安排复习时间，帮你把错题变成长时记忆
4
考试模式 → 限时组卷，检验综合掌握程度
💡 关键心态：别追求"今天把所有题都做对"，追求"每次回顾都前进一格"。间隔回顾才是这门课长期不掉队的那根线。

二、刷题模式详解

📖 顺序刷题

最适合第一遍系统学习

  • 首页点「顺序刷题」→ 出现章节列表
  • 每章有一条绿红进度条和完成百分比——一眼看出这章掌握情况
  • 点进某章后弹出一个题号网格：每个格子是一道题
    • 白底黑框 = 没做过
    • 绿底 = 答对了
    • 红底 = 答错过
  • 点任意格子直接跳那道题，不用从头刷到尾
  • 顶部「← 返回章节」可切回章节列表换章
📌 首页「继续刷题」卡片让你接着上回做到的位置练，不会丢进度。

🔀 乱序刷题

适合第二轮强化

  • 首页点「乱序刷题」→ 选择题源
    • 📚 全部题目：从题库随机抽
    • ❌ 仅错题：只抽做错的（消灭薄弱点）
    • ⭐ 仅收藏 / ❓ 仅疑点
  • 可设数量上限（默认 20 题）
  • 支持断点续练
💡 乱序 + 仅错题是最有效的第二轮复习方式，打乱顺序能暴露靠上下文推测而非真正理解的题目。

⏱️ 考试模式

模拟真实考试场景

  • 首页点「考试模式」→ 设单选/多选数量 + 考试时长
  • 限时答题，右上角有倒计时
  • 点击「答题卡」可快速跳题
  • 交卷后自动评分，显示总分和逐题解答
  • 成绩保存到成就页可随时回顾
💡 考试结果 ≥ 90% 自动解锁「学霸附体」徽章。

🔄 间隔回顾（艾宾浩斯）

长期记忆引擎

  • 首页第四格「间隔回顾」→ 显示当前待回顾题数
  • 错题自动进入回顾队列，按遗忘曲线排期：
    1天 → 3天 → 7天 → 15天 → 30天 → 毕业
  • 到期题在首页提醒，点进去逐题回顾
  • 每题显示「📝 上次错选：X」提示
  • 回顾答对→进入下一阶段；答错→回到第一天重来
  • 连续 5 轮正确后毕业，从队列移除
💡 核心：间隔回顾不在乎你今天对多少，在乎你"能不能让每道错题按自己的节奏走完五轮"。坚持就有效，断就回零。

三、作答与反馈

每道题的交互

  • 单选：点一个选项即选中；多选：点多个，再点取消
  • 点「确认」提交答案→ 当场显示 ✅/❌ + 正确答案 + 解析
  • 点「看答案」只看正确答案，不记入成绩（另设 不提交）
  • 底部可收藏 / 标记疑点

错题详情怎么看

  • 底部「错题」tab 列出所有错题
  • 点开任一错题：你当初选错的选项用红框标出，正确答案用绿框标出——两样并陈，对比学习
  • 可手动「移出错题」、收藏、标疑点

四、成就与激励

经验值与等级

  • 答对 +15 XP，答错 +5 XP；每日打卡 +10 XP
  • 每 200 XP 升一级，等级在首页 hero 栏和成就页展示

刷题热度图

位于成就页 hero 下方——"你最近有没有在坚持？"

  • 近 14 天、每天一个小方块，越红 = 刷得越多
  • 六档：
 灰→微暖→浅红→红→深红→紫

格子在一天天右移，老数据滚出、新数据进来——动态变化的。几天不用就会看到灰色蔓延，这是诚实的镜子。

其他统计

  • 章节掌握度雷达图：一眼看各章的正确率分布
  • 近 14 天正确率折线：有没有明显的进步或波动
  • 徽章墙：9 枚成就徽章（百题斩 / 七日打卡 / 学霸附体 / 错题清零等）
  • 历史成绩：每次考试的分数、答对比例、用时

五、数据与隐私

  • 一切数据都在你自己手里——存在浏览器的 localStorage 里，不上传任何服务器
  • 换个浏览器 / 清空缓存 / 隐私模式 → 进度会丢失。建议用固定设备 + 固定浏览器
  • 「我的」页面有「清空全部学习进度」按钮——不可恢复，慎点
  • 暗色模式、三档字号可在「我的」页面调整

六、推荐使用节奏

阶段内容目标
